# Data Dictionary (SYNTHETIC data)
| Column | Type | Description |
|---|---|---|
| order_id | text, unique | Order identifier, e.g. ORD-000123 (primary key; duplicates rejected) |
| order_date | date `YYYY-MM-DD` | Date of the order |
| product | text | Product name (25 fictional products) |
| category | text | Electronics, Furniture, Grocery, Apparel, Office |
| region | text | North, South, East, West, Central |
| channel | text | Online, Retail Store, Distributor, Direct Sales |
| quantity | integer > 0 | Units in the order |
| unit_price | number > 0 | List price per unit before discount (currency units) |
| discount | number 0-1 | Discount fraction (0.15 = 15%) |
| unit_cost | number >= 0 | Cost per unit (product cost only, no overheads) |
| customer_segment | text (stored as `segment`) | Consumer, Small Business, Enterprise; blank -> Unknown |
| status | text | Completed, Cancelled, Returned, Refunded |
| is_synthetic | 0/1 | 1 for generated data; imported files default to 0 |

Derived by view `valid_orders` (Completed only): `month`, `gross_revenue`, `revenue`, `cost`, `profit`.
Other tables: `sales_targets(month, region, category, channel, target_revenue)`, `import_history`, `users`.
All values are fictional and generated by `revenuelens/datagen.py` with seed 42.
